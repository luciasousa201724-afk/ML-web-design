# Guia de Imagens - ML Web Design

Este documento lista todas as imagens que devem ser providenciadas e substituídas manualmente na pasta `/dist/assets/img/`.

| Arquivo | Seção | Tamanho Ideal | Formato | Descrição |
|---------|-------|---------------|---------|-----------|
| `favicon-16x16.png` | Head (Favicon) | 16x16 | PNG | Favicon pequeno (Logo ML Web Design) |
| `favicon-32x32.png` | Head (Favicon) | 32x32 | PNG | Favicon médio (Logo ML Web Design) |
| `apple-touch-icon.png` | Head (Favicon) | 180x180 | PNG | Favicon para dispositivos Apple |
| `hero-bg.webp` | Hero (Fundo) | 1920x1080 | WebP | Foto principal da seção Hero (Ex: Ambiente moderno de tecnologia, equipe trabalhando ou laptop elegante) |
| `sobre.webp` | Quem Somos | 800x600 | WebP | Foto da equipe, da Maria Lucia ou do escritório |
| `servico-1.webp` | Serviços | 600x400 | WebP | Imagem ilustrando "Criação de Site Institucional" (Ex: Mockup de site em um monitor) |
| `servico-2.webp` | Serviços | 600x400 | WebP | Imagem ilustrando "Landing Page" (Ex: Mockup de página de alta conversão em um celular) |
| `servico-3.webp` | Serviços | 600x400 | WebP | Imagem ilustrando "Gestão de Tráfego Pago" (Ex: Gráficos de crescimento, tela de anúncios) |

**Atenção:** 
- A estrutura do projeto já busca por estes exatos nomes de arquivos dentro da pasta `assets/img/`.
- Caso não tenha as imagens no formato `.webp`, converta as imagens atuais para webp para manter a performance alta.
- Substitua também o link do Iframe do Google Maps na seção de Localização caso necessário.
